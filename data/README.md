# 요금 데이터

진단 규칙(R1~R4)이 쓰는 기준 데이터입니다. 실제 요금은 통신사 공식 페이지에서 직접 옮겨 적고, 출처와 기준일을 함께 남깁니다.

| 파일 | 내용 | 쓰는 규칙 |
| --- | --- | --- |
| `plans.json` | 통신 3사 요금제 (월정액, 기본 데이터) | R1, R4 |
| `addons.json` | 유료 부가서비스 목록과 월 요금 | R2, 고지서 항목 확인 |

## 규칙

- 값은 원 단위 정수, 부가세 포함 금액
- 무제한 데이터는 `dataGB: 9999`
- 각 파일의 `asOf`(기준일)와 `source`(출처 URL)를 반드시 채움
- 분기마다 갱신, 갱신 시 `asOf`를 바꾸고 PR로 올림
