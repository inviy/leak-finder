# 새는돈 (leak-finder)

휴대폰 요금 고지서 캡처 한 장으로 1년간 새는 통신비를 찾아 주는 모바일 웹입니다.

## MVP 범위

| 화면 | 하는 일 |
| --- | --- |
| 1 고지서 업로드 | 통신사 선택 후 캡처 위치 안내, 캡처 업로드 또는 직접 입력 |
| 2 항목 확인 | 읽어 낸 요금제, 약정, 부가서비스를 보여 주고 수정 |
| 3 결과 카드 | 1년 절감액 + 규칙별 근거, 공유 |
| 4 조치 가이드 | 항목별 신청, 해지 단계와 연락처 |

## 진단 규칙

| 규칙 | 판정 | 1년 절감액 |
| --- | --- | --- |
| R1 | 선택약정 할인 없음 (알뜰폰 제외) | 월정액 × 25% × 12 |
| R2 | 안 쓰는 유료 부가서비스 | 월 요금 합 × 12 |
| R3 | 2개월 안에 끝나는 프로모션 | 인상분 × (12 - 남은 개월) |
| R4 | 사용량보다 큰 요금제 | 한 단계 아래 요금제와 차액 × 12 |

R1과 R4가 같이 나오면 R1은 바뀐 요금제 기준으로 계산해 중복을 막습니다. 코드는 `src/lib/diagnose/`에 있습니다.

## 개발

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 진단 규칙 테스트
```

## 작업 규칙

- `main`에 직접 커밋하지 않고 브랜치 + Pull Request로 진행
- 요금 데이터는 `data/`에, 출처와 기준일을 함께 기록
